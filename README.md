## Rock Paper Scissor Game

A simple and interactive Stone Paper Scissor game built using HTML, CSS, and JavaScript.
The player competes against the computer, which generates random choices, and the result is displayed instantly based on standard game rules.

## Project Description

This project implements the classic Stone Paper Scissor game where the player selects one of the three options and the computer randomly generates its move. The game logic determines the winner based on traditional rules and displays the result immediately.

The project focuses on implementing JavaScript logic, handling user interactions, and updating the UI dynamically.

## Features

* Player vs Computer gameplay
* Random computer move generation
* Real-time result display (Win / Lose / Draw)
* Simple and user-friendly interface
* Fast and responsive gameplay

## Technologies Used

* HTML – Game structure
* CSS – Styling and layout
* JavaScript – Game logic and interaction

## Learning Outcomes

* Understanding JavaScript conditional statements
* Implementing game logic using programming concepts
* Working with DOM manipulation and event handling
* Updating UI dynamically based on user actions

## Running the Project Locally

 1. Clone the repository
```
git clone https://github.com/shubhampathare25/Rock-Paper-Scissors-Game
```
 2. Navigate to the project directory
```
cd Stone-Paper-Scissor
```
 3. Open index.html in your browser

### Usage 
   
  * How to Run: Clone the repository and open index.html in your browser or run the project using a local server.

  * Gameplay: Select your choice (Rock, Paper, or Scissors) by clicking the respective button on the UI.

  * *Winning Rules:-

  * Rock beats Scissors

  * Scissors beats Paper

  * Paper beats Rock

  * Score Tracking: The score updates automatically after each round for both the player and the computer. 

 ### Future Enhancements 
 
  * Multiplayer Mode: Add online or local 2-player support.

  * Score Persistence: Save high scores using browser localStorage so they don't reset on page refresh.

  * Sound Effects: Add audio cues for clicks, wins, and losses to make the game more engaging.
